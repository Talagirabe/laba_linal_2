### 2. Детальная математическая модель перцептрона

В основе моей модели лежит строгая математическая имитация биологического нейрона. Процесс обучения одной итерации делится на следующие шаги:

**Шаг 1. Прямой проход (Forward Pass)**
Нейрон принимает входные признаки `x1` и `x2`, умножает их на соответствующие веса `w1`, `w2` и добавляет базовое смещение `b`.

- Уравнение: `z = w1*x1 + w2*x2 + b`

Чтобы перевести полученное число `z` в удобную вероятность от 0 до 1, я пропускаю его через сигмоидальную функцию:

- `a = 1 / (1 + exp(-z))`
  _(Важное математическое свойство сигмоиды для расчетов: её производная равна `a _ (1 - a)`).\*

**Шаг 2. Оценка ошибки (Binary Cross-Entropy)**
Для оценки качества предсказания `a` относительно истинного класса `y` (0 или 1) я использовал функцию бинарной кросс-энтропии:

- `L = - [ y * ln(a) + (1 - y) * ln(1 - a) ]`
  Эта функция штрафует модель логарифмически: если истинный класс 1, формула сводится к `-ln(a)`, заставляя модель увеличивать `a`.

**Шаг 3. Обратное распространение ошибки (Backpropagation)**
Чтобы узнать, как нужно изменить веса для уменьшения ошибки, я рассчитал градиенты с помощью правила цепочки (Chain Rule). Производная ошибки по весу `w1` раскладывается на три компонента:

1. Производная ошибки по вероятности: `(a - y) / (a * (1 - a))`
2. Производная сигмоиды: `a * (1 - a)`
3. Производная суммы по весу `w1`: `x1`

При перемножении знаменатель сокращается, и получается элегантная финальная формула градиента:

- Градиент для веса: `dw1 = (a - y) * x1`
- Градиент для смещения: `db = (a - y)`

**Шаг 4. Обновление весов (SGD)**
Новые веса рассчитываются путем сдвига в сторону антиградиента с учетом скорости обучения (`lr`):

- `w_new = w_old - lr * dw`

### 3. Подготовка и предобработка данных

Качество работы любой модели напрямую зависит от данных. Я выполнил три строгих шага подготовки:

2. **Стратифицированное разбиение:** Данные поделены на обучающую (70%) и тестовую (30%) выборки. Стратификация гарантировала, что классы распределились ровно 50/50 в обеих выборках, исключив дисбаланс классов.
3. **Z-score Нормализация:** Я отцентрировал признаки так, чтобы их среднее значение равнялось нулю, а стандартное отклонение — единице: `x_norm = (x - mean) / std`. Без этого признак с большим масштабом будет "перетягивать" градиенты на себя.

### 5. Эксперименты и анализ гиперпараметров

#### 5.1. Влияние скорости обучения (Learning Rate)

Параметр определяет, насколько сильно мы сдвигаем веса в сторону антиградиента.

![Эксперимент: Скорость обучения](https://raw.githubusercontent.com/bucketio/img18/main/2026/05/27/1779875233389-2134e9a3-54a1-4e59-bbe9-c50054b95cc1.png "Эксперимент: Скорость обучения")

**Развернутый анализ:**

- **lr = 0.001 (Синяя кривая):** Слишком осторожный шаг. Модель недообучилась, застряв на высоком уровне ошибки.
- **lr = 0.01 (Оранжевая кривая):** Стабильное, но медленное обучение.
- **lr = 0.1 (Зеленая кривая - Оптимум):** Идеальный баланс. Функция потерь стремительно падает вниз без лишних колебаний.
- **lr = 1.0 (Красная кривая):** Агрессивный шаг. Алгоритм впадает в нестабильность, "перепрыгивая" локальные минимумы (видны зазубрины).

#### 5.2. Влияние размера мини-батча (Batch Size)

Размер батча определяет, по скольким объектам усредняется градиент перед обновлением весов.

![Эксперимент: Размер батча](https://raw.githubusercontent.com/bucketio/img14/main/2026/05/27/1779875401376-d1d35f49-28b0-4485-9abd-ef9e57ff8350.png "Эксперимент: Размер батча")

**Развернутый анализ:**

- **batch = 1 (Синяя кривая - SGD):** Обновление после каждого объекта. Сходимость быстрая, но график максимально шумный.
- **batch = 16 и 64 (Оранжевая и Зеленая кривые):** Оптимальный режим (Mini-batch). Градиент усредняется, шум исчезает, направление шага становится уверенным.
- **batch = 256 (Красная кривая):** Обновления слишком редкие (всего пара раз за проход всего датасета). Обучение катастрофически замедляется.

#### 5.3. Влияние инициализации начальных весов

Откуда мы начинаем спуск с горы — крайне важно.

![Эксперимент: Инициализация весов](https://raw.githubusercontent.com/bucketio/img19/main/2026/05/27/1779875455777-8487ca84-9020-44b4-8a7a-0319f6ba1227.png "Эксперимент: Инициализация весов")

**Развернутый анализ:**
Нулевая и малая инициализации идут вплотную друг к другу — это правильный подход. А вот инициализация большими весами стартует с огромного значения ошибки и сходится хуже.
_Проблема исчезающего градиента:_ Если стартовые веса огромны, сумма `w*x + b` превращается в очень большое число. Сигмоида выдает жесткую "1" или "0". График сигмоиды в этих областях становится плоским, а её производная стремится к нулю. Веса перестают корректироваться, и нейрон "умирает".

#### Бонус 2. Hinge Loss и L2-регуляризация

**Hinge Loss:** Функция потерь (используемая в SVM), которая учитывает "отступ" (margin) от разделяющей полосы. Формула: `L = max(0, 1 - y_true * z)`.

![image.png](https://raw.githubusercontent.com/bucketio/img11/main/2026/05/27/1779876947234-ade95bee-89b3-42f4-a5bc-c287c7c90e5c.png "Hinge Loss")

**L2-регуляризация:** К функции потерь добавляется штраф `+ λ * sum(w^2)`. Это предотвращает подгонку (overfitting), уменьшая норму матрицы весов.

![L2-регуляризация](https://raw.githubusercontent.com/bucketio/img1/main/2026/05/27/1779877004867-4c2db133-243d-4210-8c9c-e8ba51e8680e.png "L2-регуляризация")

#### Бонус 4. Оптимизация Momentum

Я внедрил метод Momentum, который добавляет "инерцию", сохраняя вектор скорости с прошлых шагов: `v_new = beta * v_old - lr * grad`.

-
